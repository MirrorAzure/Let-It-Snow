# Журнал изменений

[English](./CHANGELOG.md) | **Русский**

## [3.1.0] - 2026-11-03

### Добавлено
- Безопасный внешний API для управления во время работы: `burst`, `wind`, `glyphs`, `gif`, `start`, `stop`, `clearEffects` (см. [docs/EXTERNAL_API_RU.md](./docs/EXTERNAL_API_RU.md)).
- Временные слои эффектов (до 4) поверх основного снегопада с плавным затуханием и автоматическим восстановлением ветра.
- Локальный relay (`pnpm relay`): HTTP- и WebSocket-сервер без зависимостей, привязанный к loopback, с аутентификацией по токену.
- Синхронизация всех вкладок и окон, а также нескольких браузеров через relay.
- Оверлей для OBS Browser Source (`pnpm build:obs`, раздаётся relay по адресу `/obs/`) с прозрачным фоном и настройкой через query-параметры.
- Опциональный API для страниц через `window.postMessage`, ограниченный явным списком разрешённых origin.
- Новая вкладка «API» в popup: быстрые действия, настройки синхронизации, relay, API для страниц и URL для OBS (на английском и русском).
- Автономный relay без Node.js/pnpm (`pnpm build:relay`): один исполняемый файл для Windows, macOS и Linux со встроенным оверлеем OBS и постоянным файлом токена для каждого пользователя; собирается в CI и прикладывается к релизам.
- Скрипт OBS `let-it-snow-relay.lua`: запускает и останавливает relay вместе с OBS, добавляет или обновляет Browser Source с оверлеем.
- CLI relay: `--token-file`, `--pid-file`, `--parent-pid` (автоматический выход вместе с OBS), `--version`.
- Материалы для Chrome Web Store (`pnpm store:assets`, также запускается локальной `pnpm build`, пропускается в CI): `store-assets/` с английскими и русскими скриншотами реального снегопада и popup, промо-плитками и текстами описания с текущей версией.

### Улучшено
- 3D-свечение теперь строится по реальному вращающемуся 3D-силуэту с мягким размытием в экранном пространстве и плавной пульсацией; на светлых страницах оно становится белым, а не даёт тёмных ореолов.
- 3D-свечение мерцает для каждой снежинки отдельно и плавно меняется при смене фона страницы; определение фона теперь также опрашивает страницу (≈1 с) и реагирует на CSS-переходы, отслеживая смену таблиц стилей и тем во всех режимах.
- 3D-эмодзи сохраняют исходные цвета (текстурированная экструзия, как в WebGPU), а не окрашиваются палитрой. Цвет определяется по отрисованным пикселям, поэтому многоцветные глифы вроде 🦖 сохраняют цвета даже в текстовом режиме.
- Popup: новые символы автоматически получают режим текст/эмодзи (🌄, 🦖 → эмодзи); существующие пресеты переносятся однократно. Компактная шапка, закреплённый внизу блок «Старт/Стоп», необрезанные подписи подвкладок, всплывающие уведомления вместо `alert`/`confirm` (которые блокируются в popup Firefox), удаление пресета в два шага, обратная связь при действиях с пресетами, ползунок толщины 3D только в 3D-режиме, строки GIF больше не выходят за границы, более безопасное построение DOM для элементов списков.
- Пресеты применяются сразу: выбор пресета обновляет popup и уже запущенный снегопад (без кнопки «Применить»). Изменения больше не записываются в пресет молча — появляется панель «Несохранённые изменения» с кнопкой «Сохранить», черновик сохраняется при повторном открытии popup, а при переключении пресетов, импорте или восстановлении шаблонов с несохранёнными правками popup спрашивает, сохранить их как новый пресет, записать в предыдущий пресет, отменить их или отменить действие.
- Размер 3D-глифов теперь соответствует заданному размеру в единицах шрифта, как в Canvas 2D/WebGPU; предложения переносятся так же, как в 2D.
- При явном запуске снегопад начинается сверху во всех режимах (включая 3D); только автозапуск при навигации продолжает с прежнего места. Эффекты API с `entry: instant` теперь падают сверху одной плотной волной, а не заполняют экран сразу.
- GIF-снежинки в 3D-режиме кувыркаются как толстые пластины (стопка слоёв, зависящая от настройки толщины 3D) с мерцающим свечением, цвета которого берутся с краёв GIF и которое затухает на светлом фоне. Наклон ограничен, чтобы пластина никогда не становилась строго ребром: толщина остаётся видимой, а края — чёткими, без мерцания и крупных пикселей.
- GIF-снежинки получают такое же мерцающее свечение по цветам краёв в режимах WebGPU и Canvas 2D.
- Производительность 3D: объединённые грани и стенки глифов (намного меньше треугольников), обновления кадра без выделения памяти, числовая сетка столкновений, кэширование масок глифов, пропуск прохода свечения, когда оно невидимо, и автоматическое снижение pixel ratio на медленных устройствах.
- Свечение с учётом фона теперь учитывает полупрозрачные фоны страниц во всех режимах рендеринга.
- Команды запуска сохраняют выбранные режимы глифов текст/эмодзи при проверке в relay и content script.
- Popup: новая вкладка **«Помощь»** с руководством по всем функциям и интеграциям (синхронизация, relay, OBS, HTTP API и API для страниц, устранение неполадок); пункты меню верхнего уровня и подвкладок теперь одинакового размера, с выровненными иконками и подписями.
- Документация доступна на английском и русском языках (README, руководство пользователя, External API, playground, архитектура, журнал изменений).

### Безопасность
- Строгая проверка команд на каждом этапе передачи, ограничения размера данных и частоты запросов.
- Relay: сравнение токена за постоянное время, защита от DNS rebinding, список разрешённых origin, без CORS, строгая CSP для страницы OBS.
- Загрузка GIF в фоновом скрипте ограничена ответами `http(s)` с типом `image/*` размером до 15 МБ; GIF, пришедшие со страницы, никогда не загружаются через фоновый скрипт.
- Мост playground ограничен localhost; сообщения расширения принимаются только от самого расширения.

### Совместимость
- Добавлено разрешение `alarms` (поддержание соединения с relay).
- Минимальная версия Firefox теперь 112 (фоновый скрипт в виде модуля).

## [3.0.0] - 2026-10-30

### Добавлено
- Дополнительный 3D-снегопад на Three.js/WebGL2 с перспективой, вращением, ветром, взаимодействием с указателем и 3D-столкновениями.
- Пользовательские текстовые и эмодзи-глифы, цвета палитры и настраиваемая толщина экструзии в 3D-режиме.
- Свечение по форме снежинок с пульсацией в рендерерах WebGPU, Canvas 2D и 3D.
- Элементы управления playground для предпросмотра 3D, толщины экструзии и сравнения рендереров и свечения.

### Улучшено
- Работа рендереров, глифов и физики.
- Инструменты сборки и кроссбраузерная упаковка для Chrome, Firefox и Edge.

### Совместимость
- Автоматический режим рендеринга WebGPU/Canvas 2D остаётся режимом по умолчанию.
- 3D-рендеринг требует WebGL2; в неподдерживаемых окружениях используется резервный Canvas 2D.
- GIF-снежинки остаются DOM-оверлеями и не участвуют в 3D-столкновениях.
