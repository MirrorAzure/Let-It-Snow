## Описание для магазина (v3.1.0)

Let it snow добавляет на любой сайт праздничный настраиваемый снегопад.

Создайте свой зимний стиль:
- Настраивайте количество снежинок, скорость падения и диапазон размеров
- Используйте собственные символы, длинные фразы и несколько цветов
- Добавляйте анимированные GIF-снежинки по ссылке или из локальных файлов
- Взаимодействуйте со снегом мышью и touch-жестами
- Используйте автоматический рендеринг WebGPU с надежным резервным Canvas 2D
- Включайте дополнительный 3D-снегопад Three.js/WebGL2 с перспективой и вращением
- Настраивайте 3D-глифы, цвета и толщину объёмных снежинок
- Наблюдайте свечение по форме снежинок, пульсирующее вместе с ними
- Запускайте всплески снега, сильный ветер, глифы и GIF через безопасный локальный API
- Синхронизируйте снегопад во всех окнах и даже между браузерами
- Добавляйте снег в стримы OBS через прозрачный Browser Source
- Сохраняйте и переключайте пресеты под разное настроение — выбранный пресет применяется сразу, а о несохранённых изменениях popup предупредит
- Импортируйте и экспортируйте настройки в JSON
- Переносите все пресеты при импорте/экспорте одним переключателем
- Восстанавливайте встроенные шаблоны пресетов в один клик
- Пользуйтесь расширением на английском и русском языках

Идеально для праздничной атмосферы, оформления стримов, демо и просто красивого повседневного браузинга.

Изменения в версии 3.1.0:
- Добавлен безопасный внешний API (локальный relay по HTTP/WebSocket и опциональный API для страниц): всплески снега, ветер, глифы и GIF
- Добавлена синхронизация всех окон и нескольких браузеров
- Добавлен оверлей для OBS Browser Source
- Переработано свечение в 3D: мягкое и чистое, без тёмного ореола на светлых страницах

Изменения в версии 3.0.0 (с 2.0.5):
- Добавлен дополнительный 3D-режим с пользовательскими глифами, цветами, перспективой, толщиной и столкновениями
- Добавлено свечение по форме снежинок с пульсацией в WebGPU, Canvas 2D и 3D
- Улучшены стабильность рендереров, обработка глифов и физика снегопада

Конфиденциальность
Let it snow не собирает, не продает и не передает персональные данные.
Расширение работает локально в браузере и сохраняет настройки (например: количество снежинок, символы, цвета, пресеты, ширину popup и необязательные настройки API) в хранилище браузера (chrome.storage).
Аккаунт, регистрация, аналитика и трекинг не требуются.
Если вы вручную добавляете URL GIF, эти файлы запрашиваются напрямую с указанного источника в вашем браузере для отображения анимации.
Необязательное подключение к relay работает только с локальным сервером на вашем компьютере (127.0.0.1); токен доступа хранится только в локальном хранилище браузера.

## Установка и настройка

### Требования
- Node.js 22.22.2+, 24.15.0+ или 26+
- Менеджер пакетов pnpm (установка: `npm install -g pnpm`)

### Установка

1. Склонируйте проект или перейдите в его каталог
2. Установите зависимости:
```bash
pnpm install
```

### Сборка для разработки
```bash
pnpm run dev
```
Запускает сервер разработки Vite для сборки расширения.

### Сборка для продакшена
```bash
pnpm run build
```
Собирает расширение для всех браузеров и создаёт:
- Распакованные сборки в `dist/chrome`, `dist/firefox`, `dist/edge`
- Упакованные артефакты в `builds/` (ZIP для Chrome/Firefox и CRX для Edge)
- Материалы для Chrome Web Store в `store-assets/` (только при локальной сборке, пропускается, если задана переменная `CI`): локализованные скриншоты `en`/`ru` 1280×800 (24-битный PNG) реального снегопада и popup, промо-плитки 440×280 и 1400×560, а также тексты `title`/`summary`/`description` с текущей версией. Нужен локально установленный Chrome/Chromium/Edge (путь можно переопределить через `CHROME_PATH`). Пересоздать: `pnpm store:assets`; пропустить: `SKIP_STORE_ASSETS=1` или `pnpm build -- --no-store-assets`.

### Упаковка (необязательно)
```bash
pnpm run pack:chrome
pnpm run pack:firefox
pnpm run pack:edge
```
Используйте эти команды, если нужно пересоздать отдельные артефакты после сборки.

### Загрузка распакованного расширения

1. Выполните `pnpm run build`, чтобы создать сборки для каждого браузера в `dist/`.
2. В Chrome откройте `chrome://extensions/`, включите **Режим разработчика**, нажмите **Загрузить распакованное расширение** и выберите `dist/chrome`.
3. В Edge откройте `edge://extensions/`, включите **Режим разработчика**, нажмите **Загрузить распакованное** и выберите `dist/edge`.
4. В Firefox откройте `about:debugging#/runtime/this-firefox`, выберите **Загрузить временное дополнение** и укажите `dist/firefox/manifest.json`. Временные дополнения удаляются при закрытии Firefox.

Упакованные файлы релиза записываются в `builds/`.

## Диаграмма архитектуры

Материалы по архитектуре в `diagrams/` обновлены для версии **3.0.0**. См. [diagrams/architecture_RU.md](./diagrams/architecture_RU.md) (English: [diagrams/architecture.md](./diagrams/architecture.md)).

Архитектура проекта:
- **Web Pages** — веб-страницы, на которых работает расширение
- **Content Script** — основной скрипт расширения с движком снегопада
- **Renderers** — WebGPU, резервный Canvas 2D и дополнительный 3D-режим Three.js WebGL2
- **Graphics Layer** — управление атласом и uniform-буферами для WebGPU
- **Physics Layer** — симуляция, столкновения, взаимодействие с мышью и общее поле ветра
- **Shared Utilities** — стабилизация размеров viewport и вспомогательные функции кругового курсора, общие для рендереров
- **Popup UI** — интерфейс управления расширением
- **Settings Manager** — управление настройками и их сохранение
- **Localization** — поддержка английского и русского языков
- **Storage** — хранение пользовательских настроек
- **Manifest Config** — конфигурации для Chrome, Firefox и Edge

## Возможности

- **Настраиваемые снежинки**: количество, размер и скорость падения
- **Выбор цветов**: несколько цветов для снежинок
- **Настройка символов**: любые символы в качестве снежинок с переключением режима отрисовки текст/эмодзи для каждого символа
- **Пресеты**: сохранение и загрузка собственных пресетов; встроенные сезонные шаблоны («Зима», «Весна» и др.)
- **Поддержка GIF**: добавление GIF по URL или загрузкой локального файла
- **Взаимодействие с мышью**: снег можно толкать, закручивать и тянуть движением указателя
- **Мягкие столкновения**: снежинки мягко отталкиваются друг от друга
- **Дополнительный 3D-режим снега**: освещённые инстансированные глифы на выбор пользователя с цветами палитры (эмодзи сохраняют собственные цвета), настраиваемая толщина экструзии, перспектива, вращение, мерцающее свечение с учётом фона, ветер, взаимодействие с указателем и 3D-столкновения сфер. GIF вращаются с помощью CSS 3D-трансформаций, но остаются DOM-оверлеями и не сталкиваются с 3D-снегом. Автоматический режим WebGPU/Canvas по умолчанию не изменился; браузеры без WebGL2 переключаются на Canvas 2D.
- **Эффекты ветра**: физически правдоподобная симуляция ветра с турбулентностью
  - Многослойная турбулентность ветра (низкие, средние и высокие частоты)
  - Ветер действует как сила/ускорение (а не просто смещение)
  - Сопротивление ветру зависит от размера (мелкие снежинки сносит сильнее)
  - Эффект подъёма при сильном ветре
  - Двойное подвижное поле вихрей с противоположным направлением вращения
  - Случайные траектории вихрей в каждой сессии, чтобы избежать статичных «горячих точек»
  - Общий модуль физики ветра для рендереров WebGPU и Fallback 2D
- **Оценка качества атласа**: автоматический анализ сложности глифов для оптимального размера ячеек атласа WebGPU
- **Нормализация размера глифов**: общая нормализация диапазона размеров с ограничениями 2–10% и преобразованием устаревших значений
- **Вкладка «Справка»**: встроенное руководство в popup с описанием всех функций и интеграций (синхронизация, relay, OBS, HTTP API и API для страниц) на английском и русском языках
- **Вкладка «О расширении»**: версия, авторы, репозиторий и стек технологий в popup
- **Настраиваемая ширина popup**: ширина панели в процентах от экрана с мгновенным предпросмотром в % и px
- **Внешний API (3.1.0)**: команды всплеска, ветра, глифов, GIF, запуска и остановки через защищённый токеном локальный relay (HTTP + WebSocket) или опциональный API для страниц с ограничением по origin — см. [docs/EXTERNAL_API_RU.md](./docs/EXTERNAL_API_RU.md)
- **Синхронизация окон и браузеров**: рассылка во все вкладки и окна; подключение нескольких браузеров к одному relay
- **Поддержка OBS**: прозрачный оверлей для Browser Source, который раздаёт relay (`pnpm relay`, `http://127.0.0.1:8787/obs/#token=...`)
- **Сохранение настроек**: все настройки сохраняются автоматически
- **Многоязычность**: английский и русский переводы

## Сборка с Vite

Расширение собирается с помощью Vite и плагина CRXJS для расширений Chrome. Конфигурация автоматически:
- Собирает JavaScript-модули
- Обрабатывает импорты CSS
- Управляет версией в манифесте
- Оптимизирует ресурсы для продакшена

## Внешний API, синхронизация и OBS

```bash
pnpm build            # собирает расширения и dist/obs
pnpm relay            # локальный relay на 127.0.0.1:8787 (выводит токен и URL для OBS)
```

Пошаговые инструкции: [docs/USAGE_RU.md](./docs/USAGE_RU.md) (English: [docs/USAGE.md](./docs/USAGE.md)).
Полное описание протокола, ограничений и модели безопасности: [docs/EXTERNAL_API_RU.md](./docs/EXTERNAL_API_RU.md) (English: [docs/EXTERNAL_API.md](./docs/EXTERNAL_API.md)).

## Примечания

- Иконки нужно разместить в каталоге `src/icons/` (16px, 48px, 128px)
- Каталог `dist` создаётся при сборке и не должен попадать в git
- Для единообразия используйте команды `pnpm`, а не `npm`
- Разрешение `activeTab` удалено из манифестов

## Поддержка браузеров

- Chrome и браузеры на основе Chromium (Manifest V3)
- Firefox (Manifest V3)
- Автоматический рендеринг WebGPU с резервным Canvas 2D, если WebGPU недоступен
- Дополнительный 3D-режим WebGL2; при недоступности WebGL2 используется Canvas 2D
